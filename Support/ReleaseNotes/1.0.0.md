Motionpaper 首个正式版本，让系统当前选中的动态壁纸持续播放。

- 启动后自动工作，通过菜单栏图标查看播放状态和退出应用。
- 可选的“随开机自动启动”，默认关闭，菜单直接显示“是／否”。
- 内置正式版更新检查，确认后下载安装并重新启动。
- Autobuild 保持独立更新，并提供切换到正式版的菜单入口。
- 菜单可直接打开 GitHub 仓库。

安装包通用于 Apple 芯片和 Intel Mac，最低支持 macOS 15。请将 Motionpaper 拖入“应用程序”，并在系统设置中选择已下载完成、支持播放的系统动态壁纸。

当前安装包尚未经过 Apple 公证；首次打开方式见仓库中的安装说明。
